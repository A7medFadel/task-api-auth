# Task API Auth

A secure authentication REST API built with Node.js, Express, and Supabase Auth.

## Features

- User Signup
- User Login
- JWT authentication
- Protected routes
- Reusable authentication middleware
- Logout
- Swagger API documentation

## Technologies

- Node.js
- Express.js
- Supabase Auth
- JWT
- Swagger UI
- dotenv
